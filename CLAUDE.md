# Заметки для Claude

- Каркас-Проект — САПР каркасного дома на сваях. Исходники в `src/` (модули по разделам), `node build.mjs` собирает из них один `index.html` и `dist/artifact.html`. `index.html` руками не править. Карта модулей — в скилле karkas-normy. Внешние библиотеки: three.js (3D), JSZip и SheetJS (экспорт) с cdnjs.
- Единицы: геометрия — мм, нагрузки — кПа. Модель проекта — объект `P` (сохраняется в localStorage `karkas-proekt-v1`), `build(P)` строит модель `M`, `calc(M)` — проверки, `spec()` — спецификация, `makeSheets()` — листы А3 (SVG, затем DXF).
- План прямоугольный A×B. Наружные стены W1 (y=0), W2 (x=A), W3 (y=B), W4 (x=0). Перегородки `P.walls` — по осям X/Y. Проёмы `P.openings`.
- Работа идёт по разделам: сначала АР (архитектурные решения), затем КР. АР и КР используют одну модель: изменение в АР пересчитывает КР.
- Помещения: `detectRooms(M,P)` находит их по стенам; названия и назначение — `P.rooms` (привязаны к точке внутри помещения). Показатели — `tep(M)`.
- Проверка: скилл karkas-check (`node tools/check.cjs` — все шаблоны против эталона `tests/baseline.json`). Публикация: скилл karkas-publish.
- Та же программа опубликована на claude.ai: https://claude.ai/artifact/KxJ1LC4oycDUgcE3T1H6Ek. При обновлении публикуй `dist/artifact.html` (уже без обёртки документа). Сайт на GitHub Pages включает владелец в настройках репозитория (через прокси это API недоступно).
- Владелец — монтажник, не программист: объяснять простыми словами, по-русски. Расчёты — предварительные, на листах есть оговорка о проверке инженером.
