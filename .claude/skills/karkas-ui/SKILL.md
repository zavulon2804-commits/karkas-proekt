# Интерфейс Каркас-Проекта: стиль «Рулетка»

Идея: инструмент мастера на стройке. Цвет строительной рулетки — акцент, дерево — конструкции, светлый тёплый серый — фон. Смелость в одном месте: жёлтая мерная шкала по краям плана и жёлтые основные кнопки; всё остальное спокойное.

## Токены (`src/style.css`, `:root`)
- Светлая тема: `--bg #E6E3DE`, `--panel #FBFAF7`, `--ink #1F1B16`, `--muted #6B6458`, `--line #D6D1C8`, `--soft #EFEBE4`, `--accent #F4B400` (текст на нём `--accent-ink #1F1B16`), `--timber #8C5A2B`, `--wall #3A2E22`, `--canvas #F3F1EC`.
- Тёмная тема («Ночная смена», по `prefers-color-scheme` и `data-theme="dark"`): `--bg #1B232C`, `--panel #222C37`, `--ink #E2E8EF`, `--line #34424F`, `--wall #D3DDE7`, `--canvas #1F2831`; акцент тот же жёлтый.
- Шрифт Onest (Google Fonts), цифры — `tabular-nums`. Моноширинный шрифт не используем для подписей.
- Жёлтым не пишем текст на светлом фоне (мало контраста): выделение — заливкой/обводкой, подписи выделенного — `--timber`. Фокус клавиатуры — обводка `--ink`.
- SVG плана берёт цвета из токенов (`getComputedStyle`), без зашитых hex — иначе ломается тёмная тема.

## Структура
- Шапка: бренд и название проекта · лента шагов `STEPS` (1 Данные, 2 План, 3 Конструкции, 4 Чертежи и смета) · 4 показателя (площадь, материалы, отделка, расчёт) · отмена/повтор, «Справка». На десктопе в одну строку.
- Шаг = свои разделы слева (`STEPS[i].secs`, остальные `details.grp` скрываются через `applyStep()`, не пересобираются) + свои вкладки (`STEPS[i].tabs`; полоса вкладок скрыта, если вкладка одна). Переход — `setStep(k, tab)`.
- Шаблоны — только на шаге «Данные». Красная точка на шаге «Конструкции» — есть непройденные проверки.
- Планировщик: сцена с мерной шкалой (метры от угла дома, `plRulers()`), вертикальная панель значков-инструментов слева на сцене (у каждой кнопки `title` и `aria-label`), «Весь план» и «Посмотреть в 3D» справа вверху, свойства выбранного справа, строка состояния снизу (шаг привязки, координаты курсора, клавиши).

## Тексты
Простые слова монтажника, глагол на кнопке говорит, что произойдёт. Без капса, без меток над заголовками, без «→» в кнопках. Ошибка говорит, что не так и как исправить.

## Проверка
`node build.mjs && node tools/check.cjs`; снимки: десктоп 1440×900, тёмная тема (`colorScheme:'dark'`), телефон 390×844. Нет переноса шапки на десктопе, нет горизонтальной прокрутки на телефоне.
