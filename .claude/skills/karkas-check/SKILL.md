# karkas-check

1. `node build.mjs` — собрать index.html из src/.
2. `node tools/check.cjs` — сверка всех шаблонов с эталоном. `=` — совпало, `≠` — показано что изменилось (было → стало).
3. Отличия ожидаемые (меняли расчёт или листы)? Убедиться, что изменилось только задуманное, затем `node tools/check.cjs --update`.
4. Снимки листов: `node tools/check.cjs --shots=tt:АР-1,АР-3 --out=<scratchpad>` (без списка кодов — все листы шаблона). Смотреть только затронутые листы.
5. `--dxf` — дополнительно собрать DXF всех листов.
6. `node tools/types.cjs` — проверка типов TypeScript: сообщает только новые ошибки (известные — в tests/tsc-baseline.txt). Новую ошибку исправить, а не добавлять в эталон.

Не писать новых тестовых скриптов, если хватает этих флагов. three.js для тестов берётся из tools/.cache (скачивается сам через npm при первом запуске).
