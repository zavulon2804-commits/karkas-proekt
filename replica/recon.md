# Карта разбора: К3-Коттедж Каркас&Сруб (Windows, настольная САПР)

Объём: только каркасный дом — каркас стен, перекрытия, кровля, фундамент (сваи), расчёт нагрузок, чертежи для бригады, спецификация и раскрой, советы. Срубы, СИП, фахверк, газосиликат и выгрузка на станки ЧПУ — вне объёма.
Для кого: собственная работа владельца; результат — онлайн-конструктор «Каркас-Проект» (браузер, без установки).
Дата: 2026-11-15

## Как собирались сведения

Работа по принципу «чистой комнаты»: изучается, что программа делает и как ею пользуются. Не используются код, файлы, установщик, демоверсия (D103Demo), интерфейс, тексты, названия и значки оригинала. Демоверсию не запускали и не разбирали: лицензионные условия демоверсий обычно запрещают декомпиляцию и обратную разработку.

Сайт разработчика и справочная вики из облачной среды недоступны (закрыты настройками сети), поэтому сведения собраны из выдачи поиска по открытым страницам. Всё, что описано ниже, — по открытым описаниям; экраны настольной программы не наблюдались напрямую, поэтому «экраны» — это режимы и окна, описанные в справке (уверенность указана).

## Главный сценарий

Задать дом (оси, стены, проёмы, перекрытия, кровлю, фундамент) — программа сама строит конструкцию каркаса — получить чертежи для сборки, спецификацию и раскрой материалов.

```

            evidence: вики «Терминология», «Комплекты»; уверенность: высокая
Профиль     длинная деталь: доска, брус, бревно, свая; сечение, длина, марка, комплект
            evidence: вики «Терминология»; уверенность: высокая
Проём       плоскость, положение, размеры, тип; не зависит от панели
            evidence: вики «Проёмы в каркасных панелях»; уверенность: высокая
Каркас      рёбра, узлы, оси стен и балок

            уверенность: средняя
```

Связи: Проект 1-n Панель; Панель 1-n Профиль (через комплект); Плоскость 1-n Проём.

## Как это ложится на «Каркас-Проект»

У нас уже есть одна общая модель дома (`P` → `build()` → `M`): стены W1–W4, перегородки, проёмы, детали каркаса с марками, сваи, ростверк, стропила. Вместо «панелей и комплектов» оригинала — стены с автоматическим построением каркаса по технологии (канадская, финская, свободная). Это совпадает по смыслу и не копирует устройство оригинала.

## Вне объёма (не повторяем)

- Срубы, бревно, брус, СИП, фахверк, газосиликат — другие технологии, не нужны владельцу.
- Выгрузка управляющих программ на станки ЧПУ — нет станков, форматы станков закрытые.
- Чертёжный вид, оформление, значки, тексты, названия команд и отчётов оригинала.
- Код, файлы и библиотеки программы, демоверсия D103Demo.
- Фотореалистичные презентации — не нужны для работы.

## Размер

Режимов 12, сценариев 4, сущностей 6. Сложные части: произвольный (не прямоугольный) план и несколько этажей; автоматические планы монтажа и развёртки всех панелей; стропильные системы сложных крыш (вальма, ендовы); раскрой листовых материалов. Наше преимущество: расчёт стропил, стоек, свай и ветра уже есть, а у оригинала считаются только балки и за отдельные деньги.

Размер: **L** (около квартала) для полного покрытия каркасной части; ядро (прямоугольный одноэтажный дом с мансардой) уже готово.
