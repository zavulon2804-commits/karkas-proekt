## Модель: дом из прямоугольных блоков

Сейчас дом — один прямоугольник A×B, и на нём держится всё: стены W1–W4, ростверк, лаги, стропила, листы. Предлагается не «любой многоугольник», а **дом из блоков**:

```
P.blocks = [
  {id:'B1', x:0,    y:0,    A:9000, B:7000, roof:'gable', ridge:'x'},   // основной
  {id:'B2', x:9000, y:2000, A:4000, B:5000, roof:'gable', ridge:'y'}    // крыло: Г-образный дом
]
```

- Блок — прямоугольник со своим положением, размерами и своей крышей (направление конька по X или Y, уклон общий или свой).
- Г-, Т-, П-образные дома — это 2–3 блока, примыкающих сторонами. Так же устроены типовые каркасные проекты и так проще считать: каждый блок — знакомый нам прямоугольник.
- Старые проекты: `normalize()` превращает `A, B` в один блок `B1` — ничего не ломается.

## Что из чего строится

| часть | сейчас | станет |
| --- | --- | --- |
| Контур дома | прямоугольник | объединение блоков; наружный контур — ломаная из отрезков по X и Y |
| Наружные стены | W1–W4 | по одной стене на каждый отрезок контура: W1…Wn; внутри блоков на линии стыка стены нет |
| Перегородки, проёмы, помещения | как есть | как есть, координаты — от общего начала; `detectRooms` работает по ячейкам внутри контура |
| Сваи и ростверк | 4 линии + промежуточные | балки под каждой наружной стеной и по промежуточным линиям каждого блока; сваи в узлах и с шагом |
| Лаги пола | по одному пролёту | в каждом блоке поперёк его короткой стороны |
| Перекрытие и стропила | одна крыша | крыша каждого блока; на стыке блоков — ендова (крыло примыкает к скату основного блока) |
| Расчёт | как есть | по самому нагруженному элементу каждого блока; ветер — по габаритам всего дома |
| Листы | план, мансарда, кровля, Ф, КД, КР | те же, но по контуру; развёрток КД станет больше (на каждую стену) |

## Сложные места

1. **Стык крыш (ендова).** Крыло ниже или вровень с основным коньком; нужны укороченные стропила (нарожники) и ендовая балка. Первая версия: крыло той же высоты стен, конёк крыла ниже или равен основному, ендова считается как балка на две опоры.
2. **Углы контура.** Внутренний угол Г-образного дома — тёплый угол и стойки примыкания нужно строить с другой стороны.
3. **Ростверк на внутреннем углу** — свая в узле обязательно.
4. **Ветер.** Жёсткость стен считать по направлениям X и Y для всех стен контура.
5. **Мансарда** — только в основном блоке (первая версия).

## Порядок работы

1. **Сквозной минимум.** Модель блоков, `normalize()`, контур и наружные стены, план 1 этажа и 3D каркаса стен для Г-образного дома. Остальные части строятся по основному блоку, как сейчас.
2. **Фундамент и пол** для всех блоков: ростверк, сваи, лаги, лист Ф-1, Ф-2.
3. **Крыши блоков** без ендовы (отдельные крыши), затем ендова, план кровли с несколькими скатами.
4. **Расчёт** по блокам, советы, спецификация, раскрой.
5. **Шаблоны**: Г-образный дом 10×8 + 4×5, Т-образный.

Каждый шаг — проверка по скиллу karkas-normy (раздел 6): старые проекты открываются, площади сходятся, листы без наложений.
