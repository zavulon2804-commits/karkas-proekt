# Каркас-Проект

САПР каркасного дома на сваях: исходные данные, расчёт нагрузок (снег, ветер), каркас стен с укосинами или обшивкой, ростверк из бруса или пакета досок, перекрытия, стропильная система, мансарда, сваи. Чертежи (АР, КР, фундамент), спецификация пиломатериалов, раскрой, смета. Выгрузка DXF, SVG, Excel.

Программа — один файл `index.html`: скачать и открыть в браузере, установка не нужна. Для разработки исходники разложены по разделам в `src/`, файл собирается командой `node build.mjs`; проверка всех шаблонов — `node tools/check.cjs`.
